Privacidade

Política de privacidade da demo

Esta página descreve as práticas previstas para a versão demonstrativa do ERP Contábil Brasil. Ela serve como base inicial de transparência, mas deve ser revisada juridicamente antes de qualquer uso comercial real.

Dados tratados na aplicação

A aplicação pode armazenar dados de cadastro de usuários, empresas, clientes, fornecedores, contas contábeis, lançamentos e títulos financeiros criados durante o uso do sistema.

Finalidade

Os dados são usados para autenticação, organização operacional, exibição de relatórios e demonstração das funcionalidades do MVP.

Segurança

O projeto foi estruturado para não versionar secrets, usar variáveis de ambiente, isolar dados por empresa e manter testes automatizados sobre regras críticas.

Ambiente demo

Evite inserir dados reais sensíveis em ambientes de demonstração. Use dados fictícios até que exista política final revisada e ambiente de produção aprovado.
